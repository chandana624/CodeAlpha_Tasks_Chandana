# CodeAlpha Artificial Intelligence Internship Tasks

This repository contains the projects completed as part of my Artificial Intelligence Internship at CodeAlpha.

## Projects

### Task 1 – Language Translation Tool
A web-based language translation application developed using Python, Flask, and the MyMemory Translation API.

**Technologies:** Python, Flask, Requests, HTML, CSS, JavaScript

### Task 2 – FAQ Chatbot
A web-based FAQ chatbot that uses NLTK, TF-IDF, and cosine similarity to find the most suitable answer.

**Technologies:** Python, Flask, NLTK, Scikit-learn, HTML, CSS

### Task 4 – Object Detection
A web-based object detection application using the YOLO deep learning model. Users can upload an image and view detected objects with bounding boxes and labels.

**Technologies:** Python, Flask, Ultralytics YOLO, OpenCV, HTML, CSS
