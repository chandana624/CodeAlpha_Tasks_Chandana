# Language Translation Tool

## Project Description

The Language Translation Tool is a web-based application that translates text from one language to another using the MyMemory Translation API.

## Features

- Text translation
- Source language selection
- Target language selection
- Translation result display
- Copy translation option
- Simple and user-friendly interface

## Technologies Used

- Python
- Flask
- Requests
- HTML
- CSS
- JavaScript
- MyMemory Translation API

## How It Works

1. User enters text.
2. User selects the source language.
3. User selects the target language.
4. The application sends the text to the MyMemory Translation API.
5. The translated text is displayed on the webpage.
